# Rapsometeddy Voice Studio

A fresh, mobile-first voice studio for the Rapsometeddy ecosystem.

## What works now
- Browser text-to-speech with device/browser voices
- Voice picker
- Rate and pitch controls
- Speak, pause, resume and stop controls
- Responsive mobile UI
- No account, paid API or API key required
- Purple Rapsometeddy branding with crowned-R mark

## Run locally

```bash
npm install
npm run dev
```

Then open the local Next.js address in a browser.

## Deploy

This is a standard Next.js app and is ready for Vercel deployment.

## Roadmap

Audio file export, richer server-side voices, voice presets and Telegram integration can be added later. The current MVP intentionally uses the browser Speech Synthesis API so it can stay lightweight and free on mobile.
